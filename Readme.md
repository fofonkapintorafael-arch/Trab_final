# Portal sobre filmes e séries de Halloween

## Tecnologias
As tecnologias utilizadas foram arquivos html, git, GitHub e Readme.

## O que cada arquivo representa
Os arquivos terão o index, onde será a principal parte do html, tera a feature de cadastro e series, onde mostrara a parte onde foram criados os arquivos html de cada haba escolhida.

## Versões 

O projeto terá duas versões principais onde mostra o inicio e o final do projeto.

## Pull Request 

Foram feitos pull request para garantir que o arquivo principal a "main" possuisse todos os arquivos html necessarios para o funcionamento do sistema criado.
